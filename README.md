# Sistem Antrian Kafe

Program Sistem Antrian Kafe dibuat menggunakan bahasa **Java**. Proyek ini mengimplementasikan konsep:
1. **ADT (Abstract Data Type)**
2. **Inheritance**
3. **Linked List** (Single, Double, Circular)

## Deskripsi
Proyek praktikum Algoritma dan Pemrograman untuk pengelolaan antrian kafe berbasis struktur data linked list dan OOP.
